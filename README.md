# rc_car_setting

遙控車設定記錄網頁。用手機記下目前整台車的所有設定，換場地或改設定前後可以存檔比對。

## 使用方式

線上版：<https://jackhung9527.github.io/rc_car_setting/>（手機直接用瀏覽器開；設定理論在 <https://jackhung9527.github.io/rc_car_setting/theory.html>）。

也可以下載整個資料夾，用瀏覽器開 `index.html`，不需要安裝任何東西。線上版與本機檔案各有自己的儲存空間，設定不會互通，要搬的話用「匯出 CSV」「匯入 CSV」。

整站是競技風格的外觀：黑底頁首與方格旗、紅黑白為主的配色、車圖放在賽道上、示意圖與曲線圖放在深色的儀表板裡。亮色與深色跟著手機或電腦的系統設定切換。

- 總覽頁中間是車的俯視圖，設定卡片圍在四周；卡片上有幾個關鍵數值，改過的卡片會標出有幾項和原廠不同
- 點卡片進去調整。每個欄位預設就是原廠值，只需要改和原廠不同的項目
  - 數值用「−」「+」按鈕調整，按住會連續走；也可以直接點數字輸入
  - 改過的欄位左側有色條，下方出現「回原廠」按鈕
- 編輯頁上方釘著示意圖，改數值會即時變化；實線是目前的設定，虛線是原廠值
- 點欄位名稱展開說明與「調整後特性」，列出這個選項往不同方向調整時車子的變化
  - 標「說明書」的是說明書原文
  - 標「一般原則」的是 RWD 甩尾車通用調校原則，說明書沒有寫，實際感受會隨場地、輪胎、陀螺儀而不同
- 車架的「全車拉桿」卡片把六支拉桿的長度集中在一起，車圖上每支都標出長度，正在調的那支會加粗；和轉向、前懸吊、後懸吊卡片裡的是同一個值
- 車架的「改裝件」卡片列出 42 項改裝件的料號與官方產品圖，記錄每一項是未裝還是已裝；預設是 GT 套件出廠的狀態。點零件名稱，車圖會標出它的位置，並有官方產品頁的連結。產品圖連到 MST 官網，沒有網路時不會顯示
- 電變一打開就是模式 10（2WD 甩尾車）的整組出廠值；在「基本資料」換使用的模式（Preset Mode），沒改過的欄位會跟著換成那一組的出廠值
- 有可調範圍的數值欄位下方有滑桿，金色記號是原廠值的位置；有大小順序的選項下方有刻度條
- 電變的油門控制、煞車控制、進角三張卡片，編輯頁上方釘著曲線圖（柔化範圍、煞車力度、Boost 進角、Turbo 進角），改數值會即時變化，總覽頁的卡片上也有縮圖；圖是依說明書描述的規則畫的示意，不是實測資料
- 設定存在瀏覽器本機；「匯出 CSV」存成檔案，「匯入 CSV」讀回來
- 伺服機的參數要接 PG-CB63 設定盒才讀得到，說明書沒有寫出廠值，欄位一開始是空的：先用設定盒 Read Data 讀回數值再填。三張「規格」卡片是規格書的內容，只能看不能改，上方釘著扭力與速度圖、外形尺寸圖、脈寬與角度圖
- 每個子項目上方都有該產品說明書的官方下載連結

## 設定理論

頁首右邊的「設定理論」連到 `theory.html`（也可以直接開這個檔），用來快速查「這個設定往哪邊調，車子會怎樣」。內容依《XRAY 中文設定書》（原著 XRAY setup book V2.0，翻譯：快手車隊 邱建清）整理，原書談的是四驅電動房車的抓地跑法。

- 總覽頁中間是車的俯視圖，29 個設定項目圍在四周：車頭上方是轉向與前軸，左側是幾何（Camber、Caster、滾動中心、潛角、車高、軸距…），右側是避震與傳動（彈簧、阻尼、防傾桿、Droop、中單向…），車尾下方是後軸
- 點項目進內容頁：上方釘著示意圖，每個調整方向一張卡片，列出原書寫的影響，並標出是入彎、彎中還是出彎；點卡片的標題，圖會換成那個方向的狀態。下面有重點、怎麼量、怎麼調整與注意事項
- 症狀查詢：按「症狀查詢」選一個目標，例如入彎轉向不足、想增加後輪抓地力、顛簸的場地。符合的項目會亮起來並標出要往哪個方向調（例如前防傾桿「軟」），車圖上對應的部位標成紅色，原書的敘述列在車圖下方
- 關鍵字搜尋：在搜尋框打字，例如「翻車」「髮夾彎」
- 齒比的內容頁可以算終傳比與 Rollout，輸入大齒盤、馬達齒、內齒比與胎徑
- 圖是依原書的敘述自己重畫的示意圖，角度與高度放大過；滾動中心那張是照原書的作圖法算出來的
- 查詢結果是原書敘述的索引，不是針對你的車的建議；原書有幾處疑似誤植，列在總覽頁最下面

## 設定分類

設定依種類分組，每個種類底下有自己的子清單：

| 分類 | 目前有的子項目 |
| --- | --- |
| 車架 | MST RMX 4 GT |
| 陀螺儀 | Futaba GYD550 |
| 伺服機 | Power HD TDS-2 |
| 電變 | Hobbywing XERUN XR10 Pro G2 |
| 遙控器 | Futaba T10PX |

## 目前狀態

車架 MST RMX 4 GT 的 92 個設定欄位（原廠值與調整後特性），14 張卡片圍在車圖四周，另有「全車拉桿」「改裝件」「基本資料」三張；示意圖有整車俯視、前後軸正視、側視、避震、齒輪、全車拉桿、零件位置；CSV 匯出匯入。改裝件 42 項來自 MST 官方升級指南與 GT 產品頁的選配清單，其中 21 項 GT 套件已內含。

電變 Hobbywing XERUN XR10 Pro G2 的 44 個欄位，分成 6 張卡片：說明書的 31 個可調項目、十組模式的出廠值、調整後特性，加上滑桿、刻度條與四張曲線圖。

陀螺儀 Futaba GYD550 的 26 個欄位，分成 4 張卡片：本體按鈕設定的 4 項有出廠值；從遙控器 Gyro Link 無線設定的 22 項，說明書沒有寫可調範圍與出廠值，欄位一開始是空的，要填 Gyro Link 讀回來的數值。八個轉向增益曲線點會畫成曲線圖。增益與 AVCS／NORMAL 的切換屬於遙控器的設定，不在這裡。

伺服機 Power HD TDS-2 分成 5 張卡片：「設定盒參數」是 PG-CB63 設定盒的 8 個可調項目（最大輸出、啟動爆發力、死區、繃緊度、力度、剎車、中位調節、緩啟動），有可調範圍與調整後特性，設定盒說明書沒有寫 TDS-2 的出廠值，所以沒有原廠值；「設定盒記錄」2 項；「規格：電氣／機械／控制」共 26 項，出自官方規格書（8.4 V 的扭力與速度、馬達、軸承出自官網產品頁），是唯讀的。圖有設定輪廓、扭力與速度對電壓、外形尺寸圖、脈寬與輸出軸角度。

遙控器 Futaba T10PX 的 265 個欄位，分成 11 張卡片（基本設定、接收機、轉向、油門與煞車、油門曲線與速度、陀螺儀混控、行駛輔助、輔助頻道、失控保護、微調鍵與旋鈕、開關）；功能關閉時細項會收起來，全部預設值時只顯示 107 列。說明書寫明 Initial value 的 128 項標成原廠值，另外 106 項的起始值取自說明書畫面截圖。轉向、油門、煞車曲線與 Acceleration 有曲線圖。只記錄 Condition 1 的值。尚未納入：引擎車專用功能、Gyro Mixing 以外的混控、遙測、計時器、系統設定。
